AI 寫的東西有一把聲音，你一定聽過。意義硬拔高、形容詞三個一串、結尾收得整整齊齊，其實甚麼都沒有說。市面上的「去 AI 化」工具，多數只是把這層味道刮走，還你一段乾淨但平坦的文字。Rewild 做的是另一件事：把模式清走，把你自己的聲音放回去——立場、節奏、不齊整的地方。它不會替你砌事實，也不會替你安一個原本沒有的人格。

**269 條分語言的模式。五個技能。一個會讀你原文、不只是讀你改稿的檢查腳本。**

## 效果如何

被量度的有三件事，答的是三條不同的問題。

**這一版是否比上一版好？** 評審同時見到同一篇原文的兩個改寫版本，必須二揀一，不准打和——這樣測試就不會像剔格清單那樣，很快就見頂。五篇輸入，三位互不通氣的評審，沒有人知道哪一個版本出自哪一套系統。

| | 英文 | 中文 |
|---|---|---|
| 判定優於上一版 | **10 / 12（83%）** | **9 / 12（75%）** |
| 讀起來較不像機器寫 | 是 | 是 |

中文這個數字是跑了三輪才拿到的：6/12，再來 7/12，然後 9/12。每一輪都修好一個真實的缺陷。舉一個例。中文技能有四處把句末語氣詞當成要湊夠的指標，模型於是在一封內部電郵裏硬貼了個「啊」。三位評審一致否決了那一句。語氣詞現在是用來診斷，不是用來達標。

**香港的文字讀起來是否香港，台灣的讀起來是否台灣？** 這正是繁體技能真正提出的主張，所以它被直接拿去測。三篇原文，三條路（`hk`、`tw`，加一條只叫模型「用繁體中文寫得似人」的控制組），九份輸出各自蒙上一個字母，三位評審：一位中立、一位以香港讀者身份讀、一位以台灣讀者身份讀。

| | 結果 |
|---|---|
| 地區歸屬（技能輸出） | **18 / 18** |
| 自己地區的自然度排名 | **6 / 6** |

每一位評審都把每一篇文放對了邊——四輪累計 50/50，其中一輪特別補上第一輪走漏的難題：一份台灣新聞稿要香港技能改成香港的，一封香港電郵要台灣技能改成台灣的。沒有一篇被當成大陸寫的。這個結果之所以有意思，是因為控制組並不是寫得差。評審形容它流暢，單看字詞多數偏向台灣那邊，因為一個沒有指引的模型，預設伸手拿的就是那套字。它做不到的是落注：「詞彙查對了台灣，但語感與收尾仍是大陸的」。有一位評審把它三篇裏的兩篇判去了大陸。沒有地區指引的繁體中文是一種真實存在的輸出，只不過它不屬於任何人。

那一輪同時揪出三個缺陷，其中一個是任何工具都查不出來的：香港新聞稿裏的「處理到」，是粵語文法穿着標準字的外衣，字元比對的腳本完全看不見。三個都寫在 [`benchmarks/`](benchmarks/) 裏。

**一篇文可以去到幾好？** 上面兩項都是比較——這一邊對那一邊，落在哪一邊。兩邊都做對之後，它們就再講不出甚麼。所以有第三項量度，而這一項沒有上限：把一篇隨筆交給一位評審，指令全部用繁體中文寫，角色是一位三十年資歷的副刊總編輯，要它打 1 至 10 分，逐句引出讀起來像機器寫的地方，改完再交。

| | 香港 | 台灣 |
|---|---|---|
| 初稿 | 5 | 5 |
| 七輪，每輪換一位評審 | 5 → 8 | 5 → 8 |
| 結構重寫，固定同一位總編輯 | 7 → 8 → 9 | 8 → 9 |
| 終審 | **10 — 落版，唔使再改** | **10 — 簽字發稿** |

**詞彙會飽和，結構不會。** 由第二輪開始，兩位總編輯都挑不出一個字錯——「字係香港人嘅字，骨係機器嘅骨」。8 分到 10 分之間，全部是手藝分佈的問題，而它現在是五個模式庫都有的一條（見下面《為甚麼有效》）。同一個提醒要再講一次：這些評審是語言模型，不是真人讀者。流程同完整軌跡都在 [`benchmarks/`](benchmarks/)。

**比通用去 AI 工具好嗎？** 早前一次跑分是 30/30 對一個典型 24 條規則工具的 24/30，中文是 30/30 對 20/30。這個數字請當成未經確認：原始輸出沒有留低，而且那次跑分早過下面那些腳本修復。跑分的東西都在 [`benchmarks/`](benchmarks/) 裏，輸入、評分準則、控制組提示詞、盲評流程齊全，你可以自己跑一次，然後告訴我這數字不對。

> **輸入：** 在人工智能急速發展的今天，本公司一直秉持創新精神，銳意求變。全新平台為用戶帶來流暢、直觀而強大的體驗。
>
> **典型工具：** 我們做了一個平台，幫用戶省回一些時間。早期反應不錯，日常工作確實快了。
>
> **Rewild：** 我們做的產品幫人省時間，這句講得過。講到「銳意求變」，那就是虛的那一截。

典型工具把吹水改成安靜版的吹水。Rewild 直接點出來。

## 為甚麼有效

大多數去 AI 工具就二十來條通用規則。刪走「此外」，把句子長短調一調，完。表面的東西處理了，再落去就沒有。Rewild 多做的功夫，集中在六處。

**每種語言一套模式，不是一張表通用。** 英文 AI 濫用 testament 同 landscape，破折號一個接一個。中文 AI 不用語氣詞，四字成語一串一串。德文 AI 迴避 Modalpartikeln，還會把複合詞拆開寫。每種語言有自己的模式庫，來源是學術研究同偵測數據——而繁體中文再按地區分家，理由見下文。

**正確詞彙掩不住的破綻。** 每個字都用對，一篇第一人稱的文章照樣讀起來像機器造的，因為手藝分佈得太平均：段段收尾都短促乾脆，每一個提過的細節後面都有回收，數字每段派一個，口水撒得均勻而不成堆，結尾那個意象同主旨一比一對上。沒有一句寫得差，而這正是證據。把一個完美的結尾換成另一個更好的，救不到——「換衫，唔係換人」。真正要做的，是肯收得平淡，肯留一個細節不回收，肯除了一處之外通篇都含糊。五個模式庫都有這一條，每一份 `SKILL.md` 都帶着那道檢查：把每段最後一句抄出來排成一欄，然後望住那一欄。

**日常口語語域，不只公文語域。** 地區模式庫本來在政府、新聞同商業中文那邊很強，講到一個人形容自己部手機，就甚麼都沒有——而大家真正攞去改的，多數就是這種文字。現在補上了：計數機／計算機／計算器，碌／滑／刷手機，讚好／按讚／點讚，尿袋／行動電源／充電寶，還有把平台當動詞用那幾行（WhatsApp 我，對面是賴我），一句就出賣了寫的人住在哪裏。兩位母語審稿人查證過這些行，並且刪走了幾行：平板、封鎖、應用程式、截圖、結帳、追蹤、動態，兩邊讀起來都是平常字，於是列為不可入閘，另有一條回歸測試守住。把一個本來已經正確的詞反向替換，會令地區判斷變成語域錯誤，讀起來比它想修的問題更差。

**防止矯枉過正。** 每一篇都用同樣三招——短句連發、刻意的自我修正、每節一條反問——你只是造出另一套同樣易認的模板。Rewild 限制單篇的改動數量，並且輪流換。

**忠實度，不只是文風。** 這一塊，大部分工具直接跳過。一篇改寫可以一個人名一個數字都沒有編過，照樣講出原文沒有講過的話。有四種走法：

- 原文把判斷掛在別人名下，改寫刪走出處，判斷留下
- 原文只是陳述，改寫變成承諾
- 原文寫「受影響」，改寫寫「全部都用不到」
- 原文交代一個原因，改寫順手排除其他

自帶腳本靠比對改稿同原文，捉到頭三種。第四種靠寫的人，模式庫寫明了這一點。

**甚麼都不准憑空加，包括聽起來謙虛的那些。** 輸出裏每一個細節，原文都要本身已經有。這條規則以前有個漏洞：舊版本叫模型刪走無來源的吹捧之後，補一句誠實克制的第一身說法，模型照做。一篇宣傳稿長出了沒有人寫過的免責聲明。一份發佈公告，令公司認了一個原文從未提過的短處。謙虛版的發明，一樣是發明。

## 改寫流程

香港同台灣多一道前置：先對全文做一次地區掃描，查對面的用詞、譯名、大陸套語同字形錯誤。它排最前，因為地區問題同段落乾不乾淨完全無關——一段一點 AI 味都沒有的文字，一樣可以整段站錯了邊。

然後每一段在動手之前先分類。逐句去修一篇濃度很高的 AI 文字，只是把骨架擦亮，架子照樣立着，所以工作分三條路：

- **本來就似人寫？** 不動。改過頭是這類工具最常見的失手方式，乾淨的段落最多修一處。
- **只有零星痕跡？** 對住模式庫原地改掉。
- **通篇都是？** 重講一次。記下事實，把原文放到一邊，用同一個語域重新寫，寫完逐條核對回原文。

重講改的是措辭，不是次序。一篇隨筆自己講明「最重要的一課」是哪一課，你把它搬去結尾，前面指着它的鋪排就落空了。

正式文體完全不走重講這條路。新聞稿、公告、政策文字只做刪同壓，因為它們的書面骨架本身就是語域，重講會滑入聊天腔。

交付之前跑兩道檢查。一個對原文完全沒有印象的審稿人盲讀改稿，標出還像 AI 的地方。然後腳本量一次模型在自己文字裏看不見的東西，並且把改稿同原文比對。風格警告是建議，忠實度警告是缺陷。

## 繁體中文在這裏是兩種語言

最順眼的設計，是一個繁體技能加一個地區參數。這條路走不通，因為**兩地各自的母語詞彙，正好落在對方的禁用詞彙裏。**

| | 香港 | 台灣 | 大陸 |
|---|---|---|---|
| software | 軟件 | 軟體 | 软件 |
| internet | 網絡 | 網路 | 网络 |
| smart | 智能 | 智慧 | 智能 |
| project | 項目 | 專案 | 项目 |
| Trump | 特朗普 | 川普 | 特朗普 |

看表裏的 網絡、智能、項目、特朗普 這四個。它們是**台灣技能必須清走的大陸詞，同時是香港技能必須護住的香港詞。** 一張封鎖表裝不下兩套相反的規則。而地區參數一旦沒有填，模型就會取一個中間值，寫出來的正好是兩邊都不認的東西：語法沒錯的繁體中文，但不屬於任何人。

還有兩處分叉把結論釘死。譯名是這門語言裏最快的破綻，台灣讀者見到 奧巴馬，一句之內就知道不是自己人寫的。另外香港有一條台灣根本沒有的語域軸：書面語對書面粵語（係／唔／嘅／咗），這條分支放進台灣技能裏純屬死重量。

兩份模式庫都不是大陸版的翻譯。45 條大陸模式逐條審過：香港保留 29 條、改寫 15 條、刪 1 條，台灣保留 25 條、改寫 19 條、刪 1 條。然後各自再加上大陸模式庫從來沒有的地區模式，香港 21 條，台灣 21 條。兩份檔案分別有 191 段同 184 段實質內容，只有一段是逐個位元組相同。當中有幾條「改寫」其實是**撤銷**，因為原規則會把當地正常的文字判成 AI 味：

- 香港刪走「名詞化成癮」。作出／進行／予以 是香港書面中文最有辨識度的語域標記，一條去名詞化的規則，是最快把港味磨走的辦法。
- 台灣刪走「功能詞失衡」。它出自英文語料，那句「把句子寫直」的處方，同台灣天然較鬆的語域對着幹。
- 台灣那批日語底層結構（「⋯的部分」「⋯性」「⋯感」）標為母語成分並受保護。一條按大陸語感調校的去翻譯腔規則，會把它們全部鏟走，反而把文字推回大陸中性——正是這個技能要防的事。
- 香港的表情符號規則放寬了，因為香港機構的對外溝通（Facebook 專頁、WhatsApp 通知）本來就在用。

兩份模式庫最後都附一張表，列出每一條被撤銷的規則同理由，免得日後有人順手把它加回去。

## 如何使用

1. 把你要用的語言那個技能目錄（`rewild/`、`rewild-zh/`、`rewild-hk/`、`rewild-tw/` 或 `rewild-de/`）整個複製到你的技能目錄，Claude Code 是 `~/.claude/skills/`。名同內容都不要改：目錄名對應技能自己的 `name:` 欄位，`references/` 模式庫同 `scripts/` 腳本要跟着走。
2. 在其他 LLM 裏，把 `SKILL.md` 當系統提示詞貼進去，`references/patterns.md` 放在旁邊，讓模型按需要讀。
3. 講一句「rewild 一下」，然後貼你的文字。

## 自帶的檢查腳本

每個技能目錄都帶一個 [`scripts/naturalness-check.py`](rewild-hk/scripts/naturalness-check.py)，Python 3，零依賴。跑它是工作流程裏的必做步驟，不是加分項。

把原文同改稿一齊傳進去，兩半的活它都做：

```bash
python3 rewild-hk/scripts/naturalness-check.py 改稿.txt --source 原文.txt --lang hk
```

風格那一半，量的是模式庫描述的東西：句長是否平均、句子開頭是否重複、段落長短是否雷同、AI 高頻詞、連接詞密度、標點問題。忠實度那一半把兩個文本比對，查出改稿多了的人名同數字、替原文做的承諾、被搶過來的判斷、被抬高的嚴重程度。中文那邊會按結構讀人名（機構、地方、職銜前後的標記），並且解析中文數字，因為一篇寫「三個星期」「凌晨兩點」的稿，一個 ASCII 數字都沒有，數字檢查會撲空。有警告時退出碼是 1，乾淨時是 0，所以它可以直接當閘用。

`--lang hk` 同 `--lang tw` 還有第三半，而且正是風格檢查完全看不見的一半：對面地區的用詞、只有大陸才用的詞、對面的譯名、轉換後殘留的簡體字、兩邊各自的字形標準，以及那個香港文字裏不應該出現的敬稱——粵語根本沒有這個字，一個就夠把來源定在大陸。

```text
字形   香港 裏 着 身份       台灣 裡 著 身分
敬稱   香港 你（不寫 您）    台灣 您好 是正常商業客套
```

它還查地區轉換最常漏的一樣東西：**套語**。把一份香港通告改成台灣的，能換的名詞只有四個，而「是次」「謹將⋯通知如下」「鳴謝」「順頌業祺」原封不動——中文沒錯，骨頭錯了。哪些套語算產地證據、哪些只是常用，是數出來的，不是憑感覺定的：「攜手合作」在 820 萬字香港政府新聞公報裏出現過 74 次，所以它是台灣的套語，但不是台灣稿的證據，已經從那項檢查裏剔走。

它還捉一類沒有風格檢查會看的缺陷：**簡繁一對多轉換錯誤**。簡體轉繁體時，一個源字可以對應幾個目標字，轉換器會揀錯：

```text
以后 → 以後    標准 → 標準    髮展 → 發展    聯系 → 聯繫
```

左邊每一個字都是合法的繁體字，錯的只有意思，所以校對根本看不出來。

地區警告是缺陷，不是建議。風格警告才是建議：有理由的警告，好過沒有道理的改動。

還有一個模式，專治每一項單篇檢查在結構上都看不見的失敗。一口氣改五篇相關的稿，它們會收斂——段數一樣、收尾一樣、同一句話擺在同一個位置——而每一篇單獨跑都是乾淨的：

```bash
python3 rewild-hk/scripts/naturalness-check.py --siblings out1.txt out2.txt out3.txt --lang hk
```

兩次獨立的基準測試都撞到這件事，兩次都只能靠人把成品並排讀一次才發現。原文本身重疊，用詞撞到是正常的，但撞形狀，那就是同一個模板換了幾層油漆。

再有一個，針對每一輪盲審都捉到、而沒有一項檢查看過的失敗：一篇改寫在地區、語域、忠實度上全部乾淨，但它已經不再是它自己聲稱的那份文件。

```bash
python3 rewild-hk/scripts/naturalness-check.py rewrite.txt --genre outage --lang hk
```

`release`、`outage`、`pressrelease`、`notice` 四種。它只報告缺了甚麼，並且拒絕幫你填：原文本來就沒有日期沒有聯絡人，補一個是捏造，不是修補。

有一件事它做得不好，直說：攞它去跑模式庫，會滿屏警告，因為模式庫本來就在引用錯誤寫法做教材。它是給改寫稿用的。模式庫請用 `--audit`。

有幾處是求其實現就會做錯的。markdown 當正文讀，不當骨架讀：標題、程式碼區塊、表格行會跳過，列表項各自算一句。比對不受排版影響，`it's worth noting` 裏的撇號打成哪一款都照樣捉到。詞彙比對跨詞形，`streamline` 也會找到 `streamlined` 同 `streamlining`。縮寫的句號不當句末，所以 Dr. Chen shipped it at 4 p.m. 不會被算成三句。

改完模式庫跑一次 `--audit`，它會拿腳本的詞表同旁邊的模式庫對一次，把模式庫寫了、腳本卻看不見的詞列出來：

```bash
python3 rewild/scripts/naturalness-check.py --audit --lang en
```

腳本歷史上出過的每一個 bug 都有回歸測試守住，由 30 條加到現在 146 條：

```bash
python3 tests/test_checker.py
```

## 結構設計

每個技能是兩個檔案加一個腳本，這個拆法是有意的。

`SKILL.md` 是操作手冊：幾時觸發、甚麼不能動、不同文體怎樣校準、好的聲音是甚麼樣。它每一次都載入上下文，所以要精簡。

`references/patterns.md` 是診斷目錄：完整的破綻清單，帶詞表、改寫前後對照同出處。模型按需要讀其中一節，不用一開始全部載入。

測試裏還跑出一個結果，說實話有點意外：一條規則擺在哪裏，同它怎樣寫一樣重要。忠實度那幾條本來擺在講「聲音」那一節的末尾，於是模型動筆之前讀到的最後一段全部是禁令。它寫得縮手縮腳，盲測輸 5/12。一個字都沒有改，只是把同一段文字搬進「寫完之後核對」那一節，結果變成 10/12。

**Rewild 之後：**
> 今次更新加了三樣：批次處理、鍵盤快捷鍵、離線模式。都是大家開口要的。不是甚麼革新，就是一次做對了的更新。
