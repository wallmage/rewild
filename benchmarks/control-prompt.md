# Control arm prompt

This is the "typical humanizer" the README compares against: the generic
~24-rule instruction most tools ship. Paste it verbatim as a system prompt,
then give the model the input text.

Keep this fixed across runs. If you change it, the published comparison no
longer applies and you should say so.

---

Rewrite the following text so it sounds like it was written by a human rather
than by AI. Apply these rules:

1. Remove "Additionally", "Moreover", "Furthermore", "In conclusion".
2. Remove "delve", "leverage", "robust", "seamless", "testament".
3. Vary sentence length — mix short and long sentences.
4. Remove promotional adjectives and hype.
5. Cut em-dashes where they are used for drama.
6. Avoid the "not just X, it's Y" construction.
7. Break up rule-of-three lists.
8. Use contractions where the register allows.
9. Remove vague attribution like "experts believe".
10. Do not open with "In today's fast-paced world" or similar.
11. Do not end with a summary of what the reader just read.
12. Avoid nominalizations — use verbs.
13. Remove hedging stacks ("arguably", "to a certain extent").
14. Vary sentence openings; do not start everything Subject-Verb.
15. Cut bullet lists back into prose where the format is not needed.
16. Remove emoji from serious prose.
17. Remove boldface used for emphasis.
18. Avoid "it's important to note" and "it's worth noting".
19. Do not use "In the ever-evolving landscape of".
20. Replace "serves as" and "stands as" with "is".
21. Remove sycophantic phrasing.
22. Avoid Title Case headings.
23. Use varied punctuation, including questions and parentheses.
24. Make the text sound natural when read aloud.

Return only the rewritten text.
